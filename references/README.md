# mac-storage-manager references

This folder stores scoped reference notes for this skill.
Use them by trigger, not as optional background reading.

- `reappearing-folder-cleanup.md`: must use for reappearing folders, old workspaces, containers, or caches that return after deletion.
- `protected-browser-session.md`: must use for browser/OpenAI/ChatGPT session, cookie, login, or token-bearing paths.
- `hidden-home-cleanup.md`: must use for hidden-home paths, container UUID folders, root-owned cache entries, or owner mismatch cleanup.
- `historical-index-cleanup.md`: must use for repo/evidence/history cleanup and only with `--profile repo-evidence`.
- `quality-gate-checklist.md`: verification checklist before calling any cleanup pass complete.
