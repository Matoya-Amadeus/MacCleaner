# 与 Mole / Pearcleaner 的差异

> 这份文档只写**我们能自己验证的事实**（我们的代码 + 本机实测）。
> 对同类工具的描述以各自仓库为准，它们改版后本文可能过期。

## 一句话定位

| 工具 | 定位 | 形态 |
|---|---|---|
| **Mac Cleaner**（本项目） | 一个窗口里做"看清单 → 勾选 → 移入废纸篓"的清理/卸载/更新 | 本地 Web UI + 命令行 + MCP 工具，Python 内核 |
| Mole | macOS 清理与系统洞察的命令行工具 | CLI / TUI，Shell 实现 |
| Pearcleaner | macOS 应用卸载与残留清理 | 原生 macOS App |

## 功能对照

| 能力 | Mac Cleaner | Mole | Pearcleaner |
|---|---|---|---|
| 缓存 / 日志 / 临时文件清理 | ✅ 带保留期（用户缓存 1 天、日志 7 天） | ✅ | —（聚焦卸载） |
| 浏览器缓存 | ✅ Firefox / Chrome / Safari，整目录搬 | ✅ | — |
| 开发工具缓存（Xcode / 包管理器 / IDE） | ✅ | ✅ | — |
| 应用卸载 + 残留扫描 | ✅ 按 bundle id / 名称匹配，分"确定项 / 名称匹配" | — | ✅（它的核心） |
| Homebrew / npm / pip / gem / rustup / App Store 更新 | ✅ 六源并行检查 | 部分 | — |
| 自带更新器（Sparkle）应用 | ✅ 列出并引导"在应用内更新" | — | — |
| 磁盘占用分布 | ✅ 单页：容量条 + treemap + 目录清单 | ✅（`analyze`） | — |
| 系统状态（负载 / 内存 / 电池 / 节流 / 进程） | ✅ 只读 | ✅（`status`） | — |
| 清理回执（可追查每次删了什么） | ✅ JSON 回执 | 部分 | — |
| MCP / agent 可调用 | ✅ | — | — |
| 图形界面 | ✅ 本地 Web UI（WKWebView 包裹） | TUI | ✅ 原生 |

## 安全模型（这是最大的差异）

| 规则 | Mac Cleaner | 说明 |
|---|---|---|
| 删除一律进废纸篓 | ✅ | 没有任何"直接 rm"的路径；卸载、清理、残留、大文件都走废纸篓 |
| root 域（`/Library/Caches`、`/var/log`）**只测量不删除** | ✅ | 见下一节"为什么" |
| 高风险项不默认勾选 | ✅ | Downloads / Docker / 安装包需自己勾 + 确认页再确认一次 |
| 空勾选 ≠ 全选 | ✅ | 空勾选被拒绝，不会"一口气升掉/删掉所有" |
| 从不静默提权 | ✅ | 只有"测量系统目录体积"会请求一次管理员授权，且只读 |
| 网络 | 只监听 `127.0.0.1`，一次性入口链接 | 不收集遥测 |

## 为什么不做"删系统缓存/日志"（常见疑问）

你手动在 Finder 里删 `/Library/Caches/xxx`，确实是**进废纸篓**的——因为 Finder 用管理员
授权后代你移动，并写入了"放回原处"所需的元数据。

但一个第三方工具要做到同样效果，需要同时满足三件事：

1. 拿到 root 权限（每次都要输密码，或常驻特权助手）；
2. 能把 root 拥有的文件移进**当前用户**的废纸篓（`~/.Trash`），且之后用户能清空它；
3. 写入 Finder 的"放回原处"信息（Finder 私有格式）。

任何一环缺失，结果就是"删掉了但找不回来"——这与本工具的承诺冲突。

所以现在的做法是：**root 域只测量、不删除**，界面明确写"只读"。要清那部分，用 Finder 或
`sudo` 自己来；我们负责告诉你它占多少。

## 我们明确不做的事

| 事项 | 原因 |
|---|---|
| 临时文件 `$TMPDIR` 清理 | 本机实测 78 MB 里 98% 是 1 天内活跃文件，只清 1 天以上剩 0.3 MB，还会误伤运行中的应用 |
| 磁盘目录下钻浏览 | 这一页回答"谁占地方"，逐层钻对判断没有增量价值 |
| 定时/后台自动清理 | 与"用户看清单再决定"的产品前提冲突 |
| 排序条 | 列表按分类/体积固定顺序更省心（卸载页以前有，已移除） |
| 遥测 / 云同步 | 不做 |

## 取舍：慢一点，但不失控

- 扫描走缓存（`SCAN_CACHE_VERSION` 变了才重扫），但**所有慢操作先给进度页**，不让界面"点了没反应"；
- 体积按 `min(表观大小, 实际分配块)` 统计 —— 否则 Docker 的 1.8 TB 稀疏镜像会虚报成 2 TB；
- 单位统一十进制（1 GB = 1000 MB），与 Finder 一致。
